# System Health Monitor

A Linux shell script that checks the health of your system and shows warnings when usage is high.

## Features
- CPU usage check
- Memory usage check
- Disk usage check
- Warning alerts when usage crosses a threshold

## Requirements
- Linux (tested on Ubuntu 22.04)
- Bash

## Usage

    chmod +x system_health_monitor.sh
    ./system_health_monitor.sh
